# Useful desktop navigation commands

`alt + tab` = Select a window

`ctrl + enter` = Full screen

`super + shift + left or right` = Move the current window to another monitor

`super + alt + left or right` = Directly move to another window

`super + space + arrow key` = Move the window position

`super + space + backspace` = Move back to the original position

# Desktop control

`super + w` = Manage desktops

`super + ctrl + left or right` = move to another desktop

`super + ctrl + shift + left or right` = move to another desktop with the current window

# Tab control

`ctrl + pgup or pgdn` = Move to next or prev tab.

`ctrl + number` = Move that specific tab number.

`ctl + tab` = Move to the next tab

`ctl + shift + tab` = Move to the previous tab

# History

`alt + left or right` = Move forward or backward in history

`ctrl + shift + t` = Restore closed tab
